# Brand Guidelines: FlowTrack (Modern Minimalist)

**Konsep Visual:** 
Sleek, modern, dan mengurangi *cognitive load* (tidak bikin pusing saat melihat banyak angka). Desain mengadaptasi gaya *neo-brutalism* ringan atau *glassmorphism* tipis untuk kartu-kartu *dashboard*.

**Tipografi Utama:** 
- **Font Family:** Poppins (Google Fonts).
- **Penggunaan:** 
  - Header / Angka Saldo: Poppins SemiBold (600) atau Bold (700) untuk penekanan.
  - Body Text / Kategori: Poppins Regular (400).
  - Label / Status: Poppins Medium (500) dengan ukuran font lebih kecil (12px - 14px).

**Palet Warna (Modern Mode):** 
- **Background Utama:** Off-White (#F8F9FA) agar mata tidak cepat lelah.
- **Surface / Card Background:** Pure White (#FFFFFF) dengan *drop shadow* sangat halus.
- **Teks Utama:** Deep Charcoal (#1A202C) untuk kontras maksimal tanpa terlalu tajam seperti hitam pekat.
- **Aksen Positif (Sesuai Target/Hemat):** Vibrant Emerald (#10B981) — memberi kesan aman dan segar.
- **Aksen Peringatan (Overbudget):** Soft Crimson (#EF4444) — tegas tapi tidak mengintimidasi.
- **Aksen Netral / Secondary:** Slate Gray (#64748B) untuk teks pendukung dan frekuensi.
