# Personal Burn Rate Tracker

**Deskripsi Proyek:** 
Aplikasi manajemen arus kas pribadi yang menghitung "Proyeksi Saldo Ideal" secara *real-time* berdasarkan berjalannya waktu di bulan tersebut. Aplikasi memisahkan pengeluaran *lump-sum* (sekali bayar di awal) dan pengeluaran rutin berulang.

**Struktur Database Utama (Merujuk pada Data Excel):**
1. **Tabel Kategori Pengeluaran (Sheet '2026'):** Memuat Nama Item (Makan, Sewa Kos, Paket data), Kategori Sifat (Dasar, Pribadi, Hiburan), Frekuensi (Harian, Mingguan, Bulanan), dan Target Anggaran.
2. **Tabel Tracking Goals (Sheet 'Process' & 'Progress'):** Memantau alokasi sisa dana ke target spesifik (Dana Darurat, Wisuda, Balik Tegal).
3. **Tabel Transaksi Aktual:** Menyimpan riwayat pengeluaran asli.

**Fitur Utama (Frontend & Backend):**
- **Dashboard Kalkulasi Dinamis:** Mengambil saldo m-banking pengguna, lalu menguranginya dengan (Pengeluaran Bulanan + (Pengeluaran Harian/Mingguan x Waktu Berjalan)). Menghasilkan selisih overbudget/underbudget.
- **Template Plan Bulanan:** Fitur duplikasi target bulan lalu ke bulan baru tanpa ketik ulang.
- **Rekonsiliasi Bank:** Fitur unggah file CSV mutasi bank di akhir bulan untuk otomatis mengisi kolom "Realisasi/Used" dan mencocokkannya dengan "Target Anggaran".
